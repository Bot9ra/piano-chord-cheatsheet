# 🎹 Шпаргалка пианиста

Интерактивный веб-справочник для визуализации аккордов: выбираешь ноту и тип аккорда — на клавиатуре подсвечиваются нужные клавиши, и аккорд можно сразу послушать.

**Демо:** `https://Bot9ra.github.io/piano-chord-cheatsheet/`

## Возможности

- Режим «Справочник»: 12 нот × 12 типов аккордов. 6 трезвучий (мажорное, минорное, уменьшённое, увеличенное, sus2, sus4) и 6 септаккордов (доминантсептаккорд, большой мажорный, малый минорный, минорный с большой септимой, полууменьшённый, уменьшённый)
- Обращения с русскими названиями (секстаккорд, квартсекстаккорд, квинтсекстаккорд, терцквартаккорд, секундаккорд)
- Режим «Тренажёр»: сайт задаёт аккорд, а вы находите его на клавиатуре и нажимаете «Проверить»
- Клавиатура на 3 октавы (C3–B5), основной тон отмечен оранжевым
- Звук настоящего пианино: свои записи из папки `sounds/` или сэмплы рояля Salamander
- Названия нот C D E ↔ до ре ми, тёмная тема, адаптивный дизайн

## Технологии

HTML5, CSS3, JavaScript (ES6), Web Audio API. Один файл `index.html`, без фреймворков и сборки.

## Звук

Приоритет источников: (1) ваши записи в `sounds/` (имена в `sounds/README.txt`); (2) сэмплы Salamander Grand Piano (Alexander Holm, CC BY 3.0) с tonejs.github.io, нужен интернет; (3) запасной синтез. Недостающие ноты получаются изменением скорости воспроизведения ближайшей записи: `rate = 2^(Δ/12)`.

## Структура

```
├── index.html      # весь сайт
├── sounds/         # (необязательно) записи вашего пианино
└── README.md
```

## Запуск локально

Откройте `index.html` в браузере: сэмплы рояля подгрузятся из интернета. Свои записи из `sounds/` браузер при запуске двойным кликом не загрузит, для этого нужен GitHub Pages или локальный сервер (`python -m http.server`).

## Структура

```
├── index.html   # разметка
```
