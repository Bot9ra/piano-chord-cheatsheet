# 🎹 Шпаргалка пианиста

Интерактивный веб-справочник для визуализации аккордов: выбираешь ноту и тип аккорда — на клавиатуре подсвечиваются нужные клавиши, и аккорд можно сразу послушать.

**Демо:** `https://Bot9ra.github.io/piano-chord-cheatsheet/`

## Возможности

- 12 основных нот × 9 типов аккордов (мажор, минор, уменьшённый, увеличенный, sus2, sus4, 7, maj7, m7)
- Обращения аккордов (основной вид, 1-е, 2-е, 3-е)
- Визуализация на клавиатуре в 2 октавы, основная нота отмечена точкой
- Звучание аккорда целиком и по нотам (Web Audio API, без внешних файлов)
- Клик по любой клавише воспроизводит ноту
- Переключение названий нот: C D E ↔ До Ре Ми
- Таблица всех аккордов от выбранной ноты
- Адаптивный дизайн, тёмная тема, управление с клавиатуры

## Технологии

HTML5, CSS3, JavaScript (ES6), Web Audio API. Без фреймворков и сборки.

## Запуск локально

Скачайте репозиторий и откройте `index.html` в браузере. Больше ничего не нужно.

## Структура

```
├── index.html   # разметка
├── style.css    # оформление
├── script.js    # данные об аккордах, отрисовка, звук
└── README.md
```

## Как это работает

Каждый аккорд задан набором интервалов в полутонах от основной ноты, например мажор — `[0, 4, 7]`. Обращение переносит нижнюю ноту на октаву вверх. Частота ноты считается по формуле `f = 261.63 × 2^(n/12)`.
