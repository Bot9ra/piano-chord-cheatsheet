# 🎹 Шпаргалка пианиста

Интерактивный веб-справочник для визуализации аккордов: выбираешь ноту и тип аккорда — на клавиатуре подсвечиваются нужные клавиши, и аккорд можно сразу послушать.

**Демо:** `https://ВАШ-НИК.github.io/piano-chord-cheatsheet/`

## Возможности

- 12 нот × 12 типов аккордов: 6 трезвучий (мажорное, минорное, уменьшённое, увеличенное, sus2, sus4) и 6 септаккордов (доминантсептаккорд, большой мажорный, малый минорный, минорный с большой септимой, полууменьшённый, уменьшённый)
- Обращения с русскими названиями (секстаккорд, квартсекстаккорд, квинтсекстаккорд, терцквартаккорд, секундаккорд)
- Клавиатура на 3 октавы + До (C3–C6), основная нота отмечена точкой
- Звучание настоящего рояля (сэмплы Salamander Grand Piano), аккорд целиком и по нотам; без интернета включается запасной синтезированный звук
- Клик по любой клавише воспроизводит ноту
- Переключение названий нот: C D E ↔ До Ре Ми
- Таблица всех аккордов от выбранной ноты
- Адаптивный дизайн, тёмная тема, управление с клавиатуры

## Технологии

HTML5, CSS3, JavaScript (ES6), Web Audio API. Без фреймворков и сборки.

Звук: сэмплы Salamander Grand Piano (автор Alexander Holm, лицензия CC BY 3.0), подгружаются с tonejs.github.io. Для воспроизведения нужен интернет.

## Запуск локально

Скачайте репозиторий и откройте `index.html` в браузере. Больше ничего не нужно.

## Структура

```
├── index.html   # разметка
├── style.css    # оформление
```

## Как это работает

Каждый аккорд задан набором интервалов в полутонах от основной ноты, например мажор — `[0, 4, 7]`. Обращение переносит нижнюю ноту на октаву вверх. Сэмплы рояля записаны через каждые 3 полутона, остальные ноты получаются изменением скорости воспроизведения: `rate = 2^(Δ/12)`.
